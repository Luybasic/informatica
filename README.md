# informatica
Этот проект показывает, насколько хорошо я разобралась с функциями git hub.
Файлы блокнота, данные и отчет находятся в папке README
Проверяющему необходимо клонировать репозиторий
Код может выдать ошибку, если в папке data/ изменен формат или структура исходных CSV-файлов. Скрипт не проверяет корректность типов данных при ручном вводе.
В версии 1.1 добавлен файл metadata.tsv и исправлены относительные пути к данным после ревью кода для повышения переносимости проекта. Выполнить последовательный запуск всех ячеек в ноутбуке. Успешное выполнение без ошибок и создание итоговых графиков подтверждают правильность работы.
